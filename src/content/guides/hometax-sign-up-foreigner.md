### Decide what access you need

Write down one concrete goal: issue a certificate of income, check a submitted return, file income tax, or pay a notice. For a personal income task, check that you are entering as the individual concerned rather than selecting an employer or company workflow.

Membership and authentication are different. Membership creates account access; authentication establishes who is using it. A later service may request stronger authentication even after an ID and password have worked. The [official Sontax login help](https://mob.hometax.go.kr/jsonAction.do?actionId=UTBMPBAC01F001) explains that ID login has service restrictions. Use its current instructions rather than assuming every login method does the same job.

### Prepare an identity checklist

Keep the following beside you, without sending a copy to an unofficial helper:

| Record to compare | Question to resolve before retrying |
| --- | --- |
| Current residence or registration card | Am I entering the registration identifier the form actually requests? |
| Name held by the authentication provider | Which spelling and name order does that provider have on record? |
| Phone or authentication app | Can I receive and approve a request on my own device? |
| Existing Hometax account | Have I used this service before, or should I recover access? |
| Task and deadline | Do I need account registration, a tax certificate, or an actual submission? |

Do not replace a rejected foreigner registration number with a passport number or a borrowed Korean identity unless the official form explicitly provides that route. If a provider cannot verify your record, ask which identity record it is checking before changing your information.

### Register, then test one real service

1. Open [Hometax](https://www.hometax.go.kr/) directly. Choose **회원가입** (membership registration) if a new account is needed. If you previously registered, use account recovery first.
2. Follow the personal registration and identity prompts shown to you. Read the identity type and each consent item; business registration is a separate matter from creating a login.
3. Select an authentication method you can use yourself. On Sontax, the official help says simplified authentication requires a certificate already issued in the relevant provider's app. It also gives separate registration instructions for joint and financial certificates. Follow those instructions if using that route.
4. Finish the account details, sign out, then sign back in. This checks that you can repeat the process without leaving a one-time session open.
5. Open the service you need. For a certificate, check the document name and available year. For filing, confirm you can reach the correct tax service without submitting a return as a test.

The target outcome is a working route to the intended service, plus a note of the authentication method used. Keep passwords, certificate files and approval codes private.

### If registration stops halfway

Record the page title, exact error text, time, device and the method you selected. A useful support request says, for example, “The identity-provider app approved the request, but Hometax returned this error before account creation.” It identifies the failed handoff without revealing an approval code.

Ask the provider when the failure happens in its app; ask Hometax support when it happens in the tax portal. The [NTS consultation page](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7848&mi=2456) lists 126 for tax and Hometax enquiries, with ordinary consultation on weekdays, 09:00–18:00. Check the official page for current availability before calling.

### Fictional example: registration works, certificate access does not

Mina creates an ID successfully and assumes her visa paperwork is ready. When she opens the certificate service, it requests additional authentication. She completes that step and then checks the requested tax year. The useful checkpoint was opening the required document service, not merely receiving an account-completion message.

If you already have an account but access fails, use the [login troubleshooting guide](/guides/hometax-login-problems-foreigners/). Once access works, continue to the [income certificate procedure](/procedures/how-to-get-income-certificate/) or [filing procedure](/procedures/how-to-file-income-tax-on-hometax/).

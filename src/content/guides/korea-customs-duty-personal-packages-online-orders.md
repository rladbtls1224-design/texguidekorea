### Set up the recipient identity

Use the recipient's own Personal Customs Clearance Code and make the English name, phone number, address, and order details consistent. A mismatch can create a courier request or customs hold. Protect the code as personal information and update registration details when needed.

### Calculate the customs value

Keep the list price, actual payment, coupon, shipping, insurance, and currency evidence. Customs value is not always the number shown beside the item on the storefront. Use the Korea Customs Service calculator as an estimate; the exchange rate, classification, origin, and actual declaration control the final assessment.

### Check the item before ordering

Food, supplements, medicine, cosmetics, plants, animal products, alcohol, tobacco, batteries, wireless devices, and other regulated items can require permits or special review. Personal-use quantity is a factual test, and repeated or commercial-looking shipments can be handled differently.

### Respond to a clearance request

Read the courier or customs notice, confirm the declaration number, and submit only the requested evidence through the official or courier channel. Correct an inaccurate description or value promptly. Preserve the final import declaration and tax receipt for returns, warranty replacements, or any later customs-duty refund claim.
